# THE KILLER WIN MACHINE

A tiny offline-friendly Dead by Daylight killer challenge tracker.

## How to use

1. Open `index.html` in a browser.
2. Pick a killer.
3. Click **GIVE ME A RANDOM PRESET**.
4. Play your match.
5. Click **I WON** or **I LOST**.
6. Your progress is automatically saved in that browser.

You can:
- add killers you buy later
- add/edit/delete randomized perk presets
- track wins, losses, and win rate per killer
- export/import a JSON backup
- use it on desktop or mobile

## Important
The tracker stores data in your browser's localStorage. If browser site data is cleared, the records can be lost. Use **EXPORT BACKUP** occasionally if you care about the records.

The starter preset list is intentionally editable. Replace the example presets with whatever perk combinations you actually want to use.
